# 星木日历 UI 预览

维护署名为 Hank1177。本目录提供团队可读取、可独立打开的前端设计稿。

## 打开方式

下载整个目录，双击 index.html，以浏览器打开。文件需保持在同一目录。

## 可体验内容

- 木质日历和夜空流星背景，支持横向拖动切换月份。
- 第一次点击日期展开待办摘要，再次点击该日期展开详细要求。
- 新建待办时可填写分类、详细要求、截止时间，支持完成与删除。
- 手记自动保存到本机浏览器，可导出 UTF-8 BOM TXT。
- 星伴采用深色烟晶风格，切面随缓慢转动呈现明暗变化。
- 轻触星核显示下一件待办，右上角可暂停动画。

## 文件

- index.html 是页面入口。
- style.css 提供布局、材质及动画样式。
- app.js 提供日历、待办、手记与导出功能。
- day-orbit.js 提供日期的两级展开与星伴交互。
- crystal.js 绘制动态星核。
- preview-orbit.png 是星伴界面截图。

## 数据与接入状态

本版是本地 UI 预览。待办和手记保存在当前浏览器的 localStorage 中，清理浏览器数据会影响保存内容，跨设备需自行导出备份。初次打开含两条示例待办。

后续接入团队应用时，需要对接实际后端数据与模型接口。本目录无需 API Key。
