星木 · 木质日历 UI 本地预览

双击 index.html 即可在浏览器打开，无需安装依赖、无需 API Key。

可以体验：
1. 鼠标左右拖动日历纸面，或在手机上横向滑动，切换月份。
2. 点击左右按钮切月、回到今天；聚焦纸面后可按左右方向键。
3. 点击日期，添加、完成或删除待办；数据保存在当前浏览器本机。
4. 切换“手记”，自动本地保存文字并下载 TXT。
5. 导出当前查看月份的计划为中文 UTF-8 BOM TXT。
6. 星空闪烁、流星划过；右上角可暂停动画。

此版本为独立 UI 设计预览，不调用百炼、不接收钉钉或学习通、不修改服务器，也未上传 GitHub。预置的两条待办是演示内容。
数据只在本机浏览器中，不会跨设备同步；清理浏览器数据可能删除它们。重要内容请先导出。
星空、木纹、纸张效果均为本地代码绘制，无外部字体、图片或网络资源依赖。
7. 点击同一日期一次看摘要，第二次看详细要求与截止时间。点“收起”回到月历。
8. 从“星伴”进入烁空间。轻点烁查看下一条待办，点“查看当日计划”返回所选日期。
