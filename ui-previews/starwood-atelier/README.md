# 星木 · 晨光序曲

这是星木 UI 的明亮设计预览，团队可直接下载整个目录，在浏览器打开 index.html。

## 视觉与交互

- 浅橡木工作台、暖白纸张、香槟金装订细节和柔和晨蓝星空。
- 月历支持左右按钮与拖动切月，选中日期后分两级展开待办。
- 第一次点击日期显示简约摘要，再点击具体待办卡片，展开该事项的详细要求与截止时间。
- 吉祥物“烁”在月历、手记和星伴页均有体现。
- 烁会自然眨眼、轻轻悬浮、随鼠标转头，并在完成任务、添加待办和切换页面时反馈。
- 点击右下角烁或星伴页角色，可以打开学习问答面板。
- 手记与待办保存在当前浏览器，支持 UTF-8 BOM TXT 导出。
- 系统设置减少动态效果时，页面采用静态展示；右上角支持暂停背景和吉祥物的持续运动。

## 文件

index.html 是入口，style.css 提供视觉与布局。
app.js 提供月历、待办与手记逻辑，day-orbit.js 提供两级展开，
crystal.js 绘制吉祥物并处理跨页反馈。全部视觉素材在本地绘制，无外部字体、图片或脚本依赖。

## 使用状态

本目录是本地前端预览，数据在浏览器内保存。问答面板当前使用有明确标识的本地演示回复，尚未接入百炼。后续接口约定见百炼接入说明.md。
初次使用时预置两条示例待办。
同一浏览器打开不同本地预览版本时可能共享已保存的待办与手记。

## 首次进入开场

首次在当前浏览器打开时显示交互开场。轻触星光，观看流星划过并凝成烁；再次轻触烁，白光展开进入主页。完整进入或点击跳过后，localStorage 的 starwood.intro.v1 保存为 seen，后续直接进入主页。页面右上角可重看开场。

开场中途刷新会在下次重新展示。清理浏览器数据、更换浏览器或设备会重新显示。无法使用本地存储时会给出提示。减少动态效果设置下使用简短的淡入淡出。开场由 arrival.js 实现，与吉祥物共用绘制方法。

## 星伴观测站更新

开场加入程序生成的旋涡星系、环形行星、斜向星环和纵深星群。进入后及后续重新打开均默认星伴界面。星伴采用独立的靛蓝与香槟金视觉，围绕烁绘制交错椭圆轨道和流动粒子。待完成与已完成数量来自所选日期的真实本地待办。月历保留浅橡木纸面。点击“和烁聊一聊”进入现有问答，点击“展开学习计划”进入月历。

cosmos-scene.js 负责开场与星伴共用的宇宙绘制，纹理在本地生成，页面隐藏、开场覆盖或暂停时停止星伴场景的动态更新。

## 学习来源与资料导入

连接页包含钉钉、学习通、中国大学 MOOC、杭电官网与杭电学生入口。当前发布的是前端预览，官方入口登录后仍需由团队后端完成授权回调、验证与状态返回。杭电学生小程序的具体链接待管理员提供。

设置 window.STARWOOD_LEARNING = { endpoint: '/api/learning' } 后启用同源服务。前端不会保存账号密码。
- POST /authorize，输入 provider，返回官方 HTTPS 授权 url。后端须使用 state、会话绑定与许可范围校验。
- GET /connections，返回 connections 数组，各项为 provider、status、accountLabel。只有 status 为 connected 才显示已连接。
- POST /sync/settings，输入 enabled 和 intervalSeconds=60。后端保存偏好并使用调度任务执行增量抓取，需处理授权过期、限流、去重与重试。登录有效期由平台控制。
- POST /extract，multipart 文件上传，返回 items 数组，各项为 title、date（YYYY-MM-DD）、details。后台负责 PDF/DOCX/图片解析、OCR、百炼提取和输出校验。
- 平台接口需要逐个确认。浏览器打开官方登录页无法将第三方登录状态自动共享给本应用，服务部署不代表已有读取群聊权限。
- 自动同步的日历结果还需要接入团队统一日历存储接口。当前日历仅保存于用户浏览器。
本地文本导入无需服务，支持 TXT、Markdown、CSV，以日期/任务关键词提取候选事项，可编辑、核对后存入日历，并按标题和来源去重。UTF-8 与 GB18030 文本可读，文件最大 2 MB，每次最多 10 个。此模式有明确标记，未使用 AI。
