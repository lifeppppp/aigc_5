# 星木 · 晨光序曲

这是星木 UI 的明亮设计预览，团队可直接下载整个目录，在浏览器打开 index.html。

## 视觉与交互

- 浅橡木工作台、暖白纸张、香槟金装订细节和柔和晨蓝星空。
- 月历支持左右按钮与拖动切月，选中日期后分两级展开待办。
- 第一次点击日期显示简约摘要，再点击具体待办卡片，展开该事项的详细要求与截止时间。
- 吉祥物“烁”在月历、手记和星伴页均有体现。
- 烁会自然眨眼、轻轻悬浮、随鼠标转头，并在完成任务、添加待办和切换页面时反馈。
- 点击右下角烁或星伴页角色，可以打开学习问答面板。
- 手记与待办保存在当前浏览器，支持 UTF-8 BOM TXT 导出。
- 系统设置减少动态效果时，页面采用静态展示；右上角支持暂停背景和吉祥物的持续运动。

## 文件

index.html 是入口，style.css 提供视觉与布局。
app.js 提供月历、待办与手记逻辑，day-orbit.js 提供两级展开，
crystal.js 绘制吉祥物并处理跨页反馈。全部视觉素材在本地绘制，无外部字体、图片或脚本依赖。

## 使用状态

本目录是本地前端预览，数据在浏览器内保存。问答面板当前使用有明确标识的本地演示回复，尚未接入百炼。后续接口约定见百炼接入说明.md。
初次使用时预置两条示例待办。
同一浏览器打开不同本地预览版本时可能共享已保存的待办与手记。

## 首次进入开场

首次在当前浏览器打开时显示交互开场。轻触星光，观看流星划过并凝成烁；再次轻触烁，白光展开进入主页。完整进入或点击跳过后，localStorage 的 starwood.intro.v1 保存为 seen，后续直接进入主页。页面右上角可重看开场。

开场中途刷新会在下次重新展示。清理浏览器数据、更换浏览器或设备会重新显示。无法使用本地存储时会给出提示。减少动态效果设置下使用简短的淡入淡出。开场由 arrival.js 实现，与吉祥物共用绘制方法。
